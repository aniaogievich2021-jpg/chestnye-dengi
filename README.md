# Честные деньги: инструкция по публикации

Игра — один файл `index.html`. Сборка и серверная часть не нужны.

## Куда выложить
Подойдёт любой статический хостинг или раздел вашего сайта.

- **Свой сайт:** загрузите `index.html` в папку, например `/game/`. Игра откроется по адресу `https://ваш-сайт/game/`.
- **GitHub Pages:** создайте репозиторий, загрузите `index.html` в корень, затем Settings → Pages → Deploy from branch → `main` / root.
- **Встраивание в страницу:** `<iframe src="https://ваш-сайт/game/" width="960" height="680" style="border:0" allow="autoplay"></iframe>`

## Важно
- **HTTPS обязателен.** Без него не заработает кнопка «Поделиться» на телефонах. Все современные хостинги включают HTTPS по умолчанию.
- **Ссылка в тексте «Поделиться»** подставится сама: это адрес, по которому открыта игра.
- **Прогресс, достижения и рекорд** хранятся в браузере игрока (localStorage). На сервер ничего не отправляется и cookies не используются.
- **Внешних зависимостей нет:** шрифты, картинки и звуки встроены в файл.

## После публикации проверьте
1. Откройте ссылку на телефоне и компьютере.
2. Пройдите уровень, убедитесь, что слышна музыка (звук включается после первого нажатия).
3. Дойдите до сертификата (можно временно поставить `GOAL = 1` в коде) и проверьте «Сохранить PNG» и «Поделиться».
